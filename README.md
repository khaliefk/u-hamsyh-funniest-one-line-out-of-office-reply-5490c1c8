Entry for the make.fun competition
`u-hamsyh-funniest-one-line-out-of-office-reply-5490c1c8`.

The task: write the funniest one-line out-of-office email reply, one
line long, 1 to 160 characters. A judge model reads the entries two at a
time and keeps the line that gets the biggest laugh.

## The entry

> I'm out of office until Monday. If it's urgent, wait until Monday, when it will be older, slightly less urgent, and entirely my problem again.

142 characters, one line. The joke refuses the usual "if it's urgent"
escape hatch by scheduling the urgency itself: the problem ages over
the weekend and comes back as the owner's problem on Monday. It reads
like a real away message a person would actually switch on, and the
punch lands on the first read with no setup to explain.

## How it works

`main.py` (Python 3, standard library only) writes the line to
`/output/entry.txt` and checks it first: 1 to 160 characters, not blank,
a single line.

```sh
python3 main.py
```
